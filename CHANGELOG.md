# Changelog

All notable changes to this project will be documented here.

## 1.0.0 — Initial project baseline

- Added email-based authentication and workspace registration.
- Added workspace membership and role-based access control.
- Added recurring routines and idempotent work-item generation.
- Added evidence upload, SHA-256 metadata, and private downloads.
- Added transactional work-item lifecycle and reviewer decisions.
- Added append-only application-level audit events.
- Added dashboard, responsive templates, Docker Compose, tests, and CI.
